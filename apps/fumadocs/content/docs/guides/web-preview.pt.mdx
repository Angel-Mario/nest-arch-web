---
title: Pré-visualização de arquivos na web
description: Entenda o que é possível conferir no assistente do site do Nest Arch.
---

O site do Nest Arch inclui um assistente de configuração e um explorador de arquivos gerados. Ele mostra presets compatíveis e algumas seleções personalizadas.

A prévia serve para inspecionar arquivos; não instala dependências nem executa o NestJS no navegador. Use a CLI para gerar o projeto no seu computador e siga as instruções para executá-lo.

O assistente web pode ser diferente da versão publicada. Para gerar e executar, siga as opções e os próximos passos da sua versão da CLI.
