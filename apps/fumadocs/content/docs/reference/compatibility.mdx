These guides target **`@nest-arch/tui` 0.5.1**, published on npm. The release source is tagged [`@nest-arch/tui@0.5.1`](https://github.com/Angel-Mario/nest-arch/tree/%40nest-arch%2Ftui%400.5.1). This alpha release may change options and output.

The wizard accepts complete profiles through a conservative support policy. Compatibility depends on the full selection: project type, architecture, HTTP provider, API, database, ORM and version, authentication, extras, addons, formatter, and transport. A supported database or auth choice on its own does not certify every possible pairing.

## How to read support claims

| Status | Meaning |
| --- | --- |
| Selectable | The wizard presents an option in some context |
| Implemented | Generator code exists for a feature or combination |
| Validated profile | An explicit end-to-end scenario has evidence for that complete profile |
| Planned or unverified | The feature or combination should not be treated as supported |

Only use a complete profile that passes the published release's support policy. If a combination is rejected as unverified, remove optional choices or select another profile. Do not bypass the support gate by calling internal APIs.

The tag's scenario inventory includes validated standalone profiles for REST, tRPC and GraphQL, PostgreSQL/MySQL/SQLite/SQL Server and selected MongoDB configurations; Express and Fastify variants; selected Prisma, TypeORM and Drizzle integrations; and specific Passport or Better Auth compositions. Optional feature coverage varies by profile. Read the exact scenarios in the [release validation guide](https://github.com/Angel-Mario/nest-arch/blob/%40nest-arch%2Ftui%400.5.1/scripts/README.md) before depending on an integration.

## Known limits

- Nest Arch is alpha; this page does not promise arbitrary feature combinations.
- The wizard exposes a single-project type; the headless CLI also accepts monorepo and Gateway selections, subject to complete-profile validation.
- Microservice transports have distinct delivery and recovery behavior. Do not assume automatic redelivery, durable delivery, or deduplication.
- A feature generated by a template is not automatically certified for every combination.
- The website's interactive preview may represent a different development snapshot than the npm release.

Review your generated files and run the checks needed by your application before deployment.
