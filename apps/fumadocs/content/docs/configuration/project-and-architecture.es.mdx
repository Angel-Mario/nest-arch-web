---
title: Tipo de proyecto y arquitectura
description: Elige una arquitectura NestJS independiente.
---

En `@nest-arch/tui` 0.5.0 puedes elegir **Single project**. Las opciones de arquitectura incluyen NestJS API y NestJS Microservice. La generación de monorepos y API Gateway no forma parte del alcance documentado de esta release.

Una API puede usar un proveedor HTTP y una capa de API. Un microservicio se organiza alrededor de un transporte de mensajería y tiene restricciones propias para bases de datos y autenticación. Consulta la [compatibilidad](../reference/compatibility) antes de añadir funciones.
