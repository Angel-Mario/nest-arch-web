Nest Arch is an interactive terminal wizard that helps you choose a NestJS application setup and generates its initial files.

The guides on this site describe **`@nest-arch/tui` 0.5.0**. This is an alpha release: options and generated output may change. Compatibility depends on the complete selection, so start with the [quick start](/en/docs/getting-started/quick-start) and check the [compatibility guide](/en/docs/reference/compatibility) before choosing integrations.

## Start here

- [Install Nest Arch](/en/docs/getting-started/installation)
- [Generate and run your first app](/en/docs/getting-started/quick-start)
- [Understand the wizard](/en/docs/guides/wizard)
- [Check compatibility](/en/docs/reference/compatibility)

Nest Arch currently generates standalone NestJS projects. Monorepo support is planned for a future release. The browser preview belongs to the Nest Arch website; it previews generated files and does not run the project in your browser.
