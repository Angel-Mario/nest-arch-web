---
title: Usa el asistente de terminal
description: Conoce los pasos de configuración y cómo dependen unas opciones de otras.
---

El asistente pregunta el nombre del proyecto, gestor de paquetes, formatter, proveedor HTTP, tipo y arquitectura del proyecto, API, datos, autenticación, funciones opcionales, Git e instalación de dependencias.

Usa las flechas para recorrer una lista de selección única y Enter para elegir. En las selecciones múltiples puedes activar varias opciones antes de confirmar. Los pasos cambian según la configuración: sin base de datos se omite el ORM y la configuración de Ultracite aparece solo al seleccionar ese addon.

Revisa el resumen antes de generar. La inicialización de Git y la instalación de paquetes dependen de tus respuestas. Al terminar, sigue los comandos de configuración mostrados para tu proyecto.

La versión 0.5.0 genera proyectos independientes. Que Gateway aparezca entre las opciones en el código fuente no significa que monorepos estén disponibles en esta release.
