---
title: Generated scripts
description: Find the common scripts in a generated standalone NestJS project.
---

Generated scripts depend on the selected features. In the basic NestJS API template, common scripts include:

| Script       | Purpose                        |
| ------------ | ------------------------------ |
| `dev`        | Start Nest in watch mode       |
| `build`      | Compile the application        |
| `start`      | Start Nest without watch mode  |
| `start:prod` | Start the compiled application |
| `test`       | Run unit tests                 |
| `test:e2e`   | Run end-to-end tests           |

When present, run a script with your selected package manager, for example `npm run dev` or `pnpm run dev`. Extras and addons add or change scripts; inspect `package.json` before copying a command from another project.

Database projects may also define schema, client generation, and migration scripts. Nest Arch lists relevant setup steps after generation; follow that output and the [first-run guide](../getting-started/first-run.mdx).
