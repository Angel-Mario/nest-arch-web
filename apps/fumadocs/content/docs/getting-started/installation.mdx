---
title: Install Nest Arch
description: Install Nest Arch and choose the interactive wizard or headless generation.
---

The commands below use `@latest` to run the newest published release. The version reviewed for these guides is shown below the page title. Nest Arch is in alpha, and releases may change the wizard or generated files.

## Run once with npx

Use an interactive terminal and a new output directory:

```sh
npx @nest-arch/tui@latest
```

To recreate an existing project, use the version recorded in its `nest-arch.jsonc` rather than `@latest`. See [project reproduction](../guides/headless.mdx#reproduce-a-project).

## Install globally

```sh
npm install --global @nest-arch/tui@latest
nest-arch
```

Check the installed version with:

```sh
nest-arch --version
```

The published package includes the generator and templates. You do not need to clone the source repository to create an application. The wizard requires interactive keyboard input; for scripts and CI, use [headless generation](../guides/headless.mdx) with a project name or `--config`.
