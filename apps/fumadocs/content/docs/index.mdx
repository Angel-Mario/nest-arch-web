Nest Arch generates the initial files for a NestJS application through an interactive wizard or headless commands without prompts.

The guides on this site describe **`@nest-arch/tui` 0.5.1**. This is an alpha release: options and generated output may change. Compatibility depends on the complete selection, so start with the [quick start](./getting-started/quick-start.mdx) and check the [compatibility guide](./reference/compatibility.mdx) before choosing integrations.

## Start here

- [Install Nest Arch](./getting-started/installation.mdx)
- [Generate and run your first app](./getting-started/quick-start.mdx)
- [Understand the wizard](./guides/wizard.mdx)
- [Create headless projects](./guides/headless.mdx)
- [Check compatibility](./reference/compatibility.mdx)

The wizard offers standalone NestJS projects. Monorepo generation is planned for version 2.0. The CLI reference lists a parser option; that does not mean monorepo generation is a supported released feature. The browser preview belongs to the Nest Arch website; it previews generated files and does not run the project in your browser.
