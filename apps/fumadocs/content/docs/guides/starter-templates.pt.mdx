---
title: Templates iniciais
description: Escolha uma configuração predefinida e confira-a antes de gerar.
---

O menu da TUI inclui **Starter templates**, com configurações predefinidas. Os templates disponíveis podem mudar entre versões.

Use o template como um conjunto prático de escolhas, não como garantia de compatibilidade com qualquer extra. Confira o resumo, consulte o [guia de compatibilidade](../reference/compatibility) e siga os passos exibidos depois da geração.

Para começar, siga o [início rápido](../getting-started/quick-start) de uma API REST sem banco de dados externo.
