title: Tipo de proyecto y arquitectura
description: Elige una arquitectura NestJS independiente.
---

El asistente de `@nest-arch/tui` ofrece **Single project**, NestJS API y NestJS Microservice. La generación de monorepos y Gateway está prevista para la versión 2.0. Que una opción figure en la referencia técnica de la CLI no significa que esté disponible en el asistente o que sea una capacidad publicada y compatible.

Una API puede usar un proveedor HTTP y una capa de API. Un microservicio se organiza alrededor de un transporte de mensajería y tiene restricciones propias para bases de datos y autenticación. Consulta la [compatibilidad](../reference/compatibility.mdx) antes de añadir funciones.
