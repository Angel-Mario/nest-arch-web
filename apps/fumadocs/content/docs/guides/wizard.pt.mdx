---
title: Use o assistente de terminal
description: Conheça as etapas de configuração e as dependências entre opções.
---

O assistente pergunta o nome do projeto, gerenciador de pacotes, formatter, provedor HTTP, tipo e arquitetura do projeto, API, dados, autenticação, recursos opcionais, Git e instalação de dependências.

Use as setas para navegar em uma lista de seleção única e Enter para escolher. Nas etapas de seleção múltipla, ative as opções desejadas antes de confirmar. As etapas dependem das escolhas: sem banco de dados o ORM é omitido; a configuração do Ultracite aparece somente quando esse addon é selecionado.

Confira o resumo antes de gerar. A inicialização do Git e a instalação de pacotes dependem das suas escolhas. Ao terminar, siga os comandos de configuração mostrados para o projeto.

A versão 0.5.0 gera projetos independentes. A presença da opção Gateway no código-fonte não significa que monorepos estejam disponíveis nesta versão.
