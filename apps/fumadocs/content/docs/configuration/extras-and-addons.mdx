---
title: Extras and addons
description: Review optional health, Docker, API, and developer-tooling additions.
---

Depending on the project profile, the wizard can offer extras such as Docker, health checks, rate limiting, Swagger, a Todo example, or TypeScript 7. Addons include Husky, Ultracite, agent skills, NestJS-Zod, and Scalar UI.

Options are filtered by project choices. Some features depend on Express or Fastify, REST or GraphQL, a database, or a particular ORM. A feature being available in the selection list does not certify every combination. Verify the full selection in the [compatibility guide](../reference/compatibility).

Read the generated next steps after adding database or authentication features; setup can include migrations, generated clients, or services. Only run commands and scripts present in your project's `package.json`.
