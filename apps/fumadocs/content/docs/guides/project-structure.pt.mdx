---
title: Explore o projeto gerado
description: Encontre os arquivos de entrada e configurações comuns de uma aplicação NestJS.
---

A estrutura depende das suas escolhas. Uma API simples costuma ter `src/main.ts` para iniciar o NestJS, `src/app.module.ts` como módulo raiz, um controller e service de exemplo em `src/`, testes em `test/` e `package.json` com scripts e dependências selecionados.

Adaptadores de banco de dados, autenticação, health checks, Docker e exemplos aparecem conforme as opções escolhidas. Confira `package.json` e os próximos passos antes de presumir que um arquivo ou comando existe.

Você pode modificar os arquivos gerados à vontade. O Nest Arch cria o ponto de partida, mas não sincroniza seu projeto com versões posteriores da CLI.
