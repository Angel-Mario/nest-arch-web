title: Project type and architecture
description: Choose the standalone NestJS architecture that fits your application.
---

The `@nest-arch/tui` 0.5.1 wizard offers **Single project**, NestJS API, and NestJS Microservice. The [headless CLI](../guides/headless.mdx) also accepts `--project-type monorepo` and `--architecture nest-gateway`; parser acceptance does not guarantee every combination is supported.

An API project can use an HTTP provider and an API layer. A microservice project is organized around a messaging transport; database access and transport combinations have their own compatibility constraints. Check the [compatibility reference](../reference/compatibility.mdx) before adding a database, authentication, or other features to a transport profile.

Use a complete profile accepted by the release's support policy for either generation method.
