---
title: Instalar Nest Arch
description: Ejecuta el asistente interactivo de terminal de Nest Arch.
---

Estas instrucciones corresponden a **`@nest-arch/tui` 0.5.0**. Nest Arch está en fase alpha; otras versiones pueden cambiar el asistente y los archivos generados.

## Ejecución puntual con npx

Usa una terminal interactiva y una carpeta nueva para el proyecto:

```sh
npx @nest-arch/tui@0.5.0
```

Para usar la versión más reciente publicada, ejecuta `npx @nest-arch/tui@latest`.

## Instalación global

```sh
npm install --global @nest-arch/tui@0.5.0
nest-arch
```

Consulta la versión instalada con `nest-arch --version`. No necesitas clonar el repositorio para generar una aplicación. Evita ejecutar el comando desde un proceso sin entrada interactiva.
