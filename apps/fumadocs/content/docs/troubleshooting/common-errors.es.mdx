---
title: Errores frecuentes
description: Diagnostica problemas de instalación, configuración y arranque.
---

**El asistente no inicia.** Usa una terminal interactiva y prueba `npx @nest-arch/tui@0.5.1`. Comprueba que Node.js y npm estén disponibles.

**No se encuentra el gestor de paquetes.** Instala el gestor seleccionado o elige otro. Si omitiste la instalación, ejecuta el comando correspondiente dentro del proyecto.

**El generador rechaza una selección.** La compatibilidad depende de la combinación completa. Quita opciones opcionales y consulta la [guía de compatibilidad](../reference/compatibility.mdx).

**La aplicación no conecta con un servicio.** Comprueba `.env`, la dirección, el puerto, las credenciales y que la base de datos o broker estén ejecutándose. SQL Server necesita una base existente y SQLite una ruta escribible.

**Falla un paso de autenticación.** Comprueba variables y ejecuta los comandos de esquema o migración impresos para ese perfil. Mantén los secretos fuera del repositorio.

**Falta un script.** Los scripts dependen de las selecciones. Comprueba `package.json` y el resumen de pasos.
