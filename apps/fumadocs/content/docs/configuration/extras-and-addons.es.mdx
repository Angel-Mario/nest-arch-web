description: Revisa las funciones opcionales y sus requisitos.

Según el perfil, puedes encontrar extras como Docker, health checks, limitación de solicitudes, Swagger, un ejemplo Todo o TypeScript 7. Los addons incluyen Husky, Ultracite, agent skills, NestJS-Zod y Scalar UI.

El asistente filtra opciones según el proyecto, proveedor HTTP, API, base de datos y ORM. Que un extra aparezca no certifica todas las combinaciones. Consulta la [guía de compatibilidad](../reference/compatibility) y sigue los pasos generados.
