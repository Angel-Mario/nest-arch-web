---
title: Scripts gerados
description: Encontre scripts comuns em uma aplicação NestJS independente.
---

Os scripts dependem das opções. Uma API NestJS básica costuma incluir `dev` para iniciar o Nest em modo watch, `build` para compilar, `start` para iniciar sem watch, `start:prod` para executar o resultado compilado, `test` para testes unitários e `test:e2e` para testes de ponta a ponta.

Use o gerenciador escolhido, como `npm run dev` ou `pnpm run dev`. Extras podem adicionar scripts. Confira `package.json` antes de executar comandos de outro projeto.

Projetos com bancos de dados podem incluir geração de clientes e migrações. Siga os próximos passos após a geração.
