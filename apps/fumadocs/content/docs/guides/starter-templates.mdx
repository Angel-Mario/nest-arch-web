---
title: Starter templates
description: Choose a preset configuration and review it before project generation.
---

The TUI includes a **Starter templates** menu alongside the new-project wizard. Templates provide predefined configurations to start from; available presets can change between releases.

Treat a preset as a convenient set of selections, not as a guarantee that every optional feature can be combined with it. Review the configuration summary, use the compatibility guide for integrations, and follow the setup steps shown after generation.

For a first project, the [quick start](../getting-started/quick-start) walks through a minimal standalone REST API without an external database.
