---
title: Vista previa de archivos en la web
description: Conoce qué puedes revisar con el asistente del sitio de Nest Arch.
---

El sitio web de Nest Arch incluye un asistente de configuración y un explorador de archivos generados. Puede mostrar presets admitidos y algunas selecciones personalizadas.

La vista previa sirve para inspeccionar archivos; no instala dependencias ni ejecuta NestJS en el navegador. Usa la CLI para generar el proyecto en tu equipo y sigue sus instrucciones para ejecutarlo.

El asistente web y la versión publicada pueden diferir. Para generar y ejecutar, sigue las opciones y los pasos de tu release de la CLI.
