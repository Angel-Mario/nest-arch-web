---
title: Proveedores HTTP y capas de API
description: Conoce las opciones Express, Fastify, REST, tRPC y GraphQL.
---

Para una API HTTP, el asistente ofrece Express o Fastify y una capa de API. REST es una opción sencilla para empezar; tRPC añade procedimientos tipados y GraphQL crea una API GraphQL con requisitos de compatibilidad propios.

Que una opción aparezca en el asistente no certifica todas sus combinaciones. El soporte depende del proveedor, API, base de datos, ORM, autenticación y extras elegidos. Consulta la [compatibilidad](../reference/compatibility).

NestJS Microservice usa transportes como Redis, MQTT, NATS, RabbitMQ, Kafka o gRPC; no son proveedores HTTP. Revisa los límites de entrega y recuperación antes de depender de un comportamiento concreto.
