---
title: Referencia de la CLI
description: Instala, ejecuta y consulta la versión del asistente Nest Arch.
---

El paquete `@nest-arch/tui` publica el ejecutable `nest-arch`.

| Acción | Comando |
| --- | --- |
| Ejecutar 0.5.0 una vez | `npx @nest-arch/tui@0.5.0` |
| Ejecutar la versión más reciente | `npx @nest-arch/tui@latest` |
| Instalar 0.5.0 globalmente | `npm install --global @nest-arch/tui@0.5.0` |
| Iniciar la instalación global | `nest-arch` |
| Consultar la versión | `nest-arch --version` |

Ejecuta la CLI en una terminal interactiva, desde la carpeta donde quieres crear el proyecto. Usa una carpeta de salida nueva. Este paquete de TUI no publica el comando `generate:module`.
