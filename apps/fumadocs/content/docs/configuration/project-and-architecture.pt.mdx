---
title: Tipo de projeto e arquitetura
description: Escolha uma arquitetura NestJS independente.
---

O assistente de `@nest-arch/tui` 0.5.1 oferece **Single project**, NestJS API e NestJS Microservice. A [CLI headless](../guides/headless.mdx) também aceita `--project-type monorepo` e `--architecture nest-gateway`; um valor aceito pelo parser não garante que qualquer combinação seja suportada.

Uma API pode usar um provedor HTTP e uma camada de API. Um microsserviço é organizado em torno de um transporte de mensagens e tem restrições próprias para bancos de dados e autenticação. Consulte a [compatibilidade](../reference/compatibility.mdx) antes de adicionar recursos.
