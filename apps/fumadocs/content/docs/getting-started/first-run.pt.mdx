---
title: Primeira execução
description: Siga os passos gerados e inicie sua aplicação NestJS.
---

Depois de gerar o projeto, o Nest Arch mostra os próximos passos para as opções escolhidas. Siga-os em ordem: alguns projetos precisam configurar um banco de dados, gerar código ou iniciar serviços antes de executar.

Se as dependências não foram instaladas, entre no diretório e use o comando do gerenciador escolhido, como `npm install`.

Se o projeto usa um banco de dados, configure `.env` e verifique se o serviço está disponível. A autenticação pode exigir segredos, uma URL pública da aplicação e uma migração ou geração de esquema. Use o arquivo de exemplo do projeto e o [guia de autenticação](../configuration/authentication.mdx); não publique segredos reais.

Execute somente os comandos de instalação, geração ou migração exibidos pelo Nest Arch. Depois, inicie o servidor de desenvolvimento com `npm run dev` (ou o gerenciador escolhido). Os passos dependem da configuração completa.
