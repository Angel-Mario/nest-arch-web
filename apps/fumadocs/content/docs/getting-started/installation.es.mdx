title: Instalar Nest Arch

---

Los comandos usan `@latest` para ejecutar la versión más reciente publicada. Debajo del título se indica la versión revisada para estas guías. Nest Arch está en fase alpha; las versiones pueden cambiar el asistente y los archivos generados.

## Ejecución puntual con npx

Usa una terminal interactiva y una carpeta nueva para el proyecto:

```sh
npx @nest-arch/tui@latest
```

Para recrear un proyecto existente, usa la versión registrada en su `nest-arch.jsonc` en lugar de `@latest`. Consulta la [reproducción de proyectos](../guides/headless.mdx#reproducir-un-proyecto).

## Instalación global

```sh
npm install --global @nest-arch/tui@latest
nest-arch
```

Consulta la versión instalada con `nest-arch --version`. No necesitas clonar el repositorio para generar una aplicación. El asistente requiere entrada interactiva; para scripts y CI, usa la [generación headless](../guides/headless.mdx) con un nombre de proyecto o `--config`.
