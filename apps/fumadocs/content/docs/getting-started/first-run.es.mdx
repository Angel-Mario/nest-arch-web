---
title: Primera ejecución
description: Sigue los pasos generados y ejecuta tu aplicación NestJS.
---

Después de generar el proyecto, Nest Arch muestra los pasos que corresponden a tus selecciones. Síguelos en orden: algunos proyectos requieren configurar una base de datos, generar código o iniciar servicios antes de arrancar.

Si no instalaste las dependencias, entra en el directorio y ejecuta el comando de tu gestor de paquetes, por ejemplo `npm install`.

Cuando el proyecto use una base de datos, configura `.env` y comprueba que el servicio esté disponible. La autenticación puede requerir secretos, una URL de aplicación y una migración o generación de esquema. Usa el archivo de ejemplo del proyecto y la [guía de autenticación](../configuration/authentication); no publiques secretos reales.

Ejecuta solo los comandos de instalación, generación o migración que Nest Arch haya impreso para tu proyecto. Después, arranca el servidor de desarrollo con `npm run dev` (o el gestor elegido). Los pasos exactos dependen de la configuración completa.
