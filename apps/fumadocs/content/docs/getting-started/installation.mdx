---
title: Install Nest Arch
description: Install Nest Arch and choose the interactive wizard or headless generation.
---

The instructions on this site target **`@nest-arch/tui` 0.5.1**. Nest Arch is in alpha, and later releases may change the wizard or generated files.

## Run once with npx

Use an interactive terminal and a new output directory. Pin the version to reproduce these guides:

```sh
npx @nest-arch/tui@0.5.1
```

To run the newest published release instead, use `npx @nest-arch/tui@latest`.

## Install globally

```sh
npm install --global @nest-arch/tui@0.5.1
nest-arch
```

Check the installed version with:

```sh
nest-arch --version
```

The published package includes the generator and templates. You do not need to clone the source repository to create an application. The wizard requires interactive keyboard input; for scripts and CI, use [headless generation](../guides/headless.mdx) with a project name or `--config`.
