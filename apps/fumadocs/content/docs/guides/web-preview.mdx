---
title: Preview project files on the website
description: Understand what the Nest Arch browser wizard can preview before using the CLI.
---

The Nest Arch website includes a browser-based configuration wizard and a project file explorer. It can show files from supported presets and from some custom selections.

The web preview is for inspecting the generated project structure and file contents. It does not install dependencies or run a NestJS application in the browser. Use the terminal CLI to generate a project on your machine and follow its setup steps to run it.

The web wizard and the published CLI can differ. When an option, profile, or output does not match, use the installed CLI release and its generated next steps as the guide for your project.
