---
title: Scripts generados
description: Encuentra los scripts habituales en una aplicación NestJS independiente.
---

Los scripts dependen de las opciones. Una API NestJS básica suele incluir `dev` para iniciar Nest en modo watch, `build` para compilar, `start` para iniciar sin watch, `start:prod` para ejecutar el resultado compilado, `test` para las pruebas unitarias y `test:e2e` para las pruebas de extremo a extremo.

Usa el gestor elegido, por ejemplo `npm run dev` o `pnpm run dev`. Los extras pueden añadir scripts. Consulta `package.json` antes de ejecutar comandos de otro proyecto.

Los proyectos con bases de datos pueden añadir generación de clientes y migraciones. Sigue los pasos posteriores a la generación.
