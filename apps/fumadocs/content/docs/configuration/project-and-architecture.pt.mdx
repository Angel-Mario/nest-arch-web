---
title: Tipo de projeto e arquitetura
description: Escolha uma arquitetura NestJS independente.
---

No `@nest-arch/tui` 0.5.0, é possível escolher **Single project**. As opções de arquitetura incluem NestJS API e NestJS Microservice. A geração de monorepos e API Gateway não faz parte do escopo documentado desta versão.

Uma API pode usar um provedor HTTP e uma camada de API. Um microsserviço é organizado em torno de um transporte de mensagens e tem restrições próprias para bancos de dados e autenticação. Consulte a [compatibilidade](../reference/compatibility) antes de adicionar recursos.
