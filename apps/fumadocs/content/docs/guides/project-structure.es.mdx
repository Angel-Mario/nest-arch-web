---
title: Explora el proyecto generado
description: Encuentra los puntos de entrada y archivos habituales de una aplicación NestJS.
---

El árbol depende de tus selecciones. Una API sencilla suele tener `src/main.ts` para iniciar NestJS, `src/app.module.ts` para el módulo raíz, un controlador y un servicio de ejemplo en `src/`, pruebas en `test/` y `package.json` con los scripts y dependencias seleccionados.

Los adaptadores de base de datos, autenticación, health checks, Docker y ejemplos aparecen solo cuando corresponden. Revisa `package.json` y los siguientes pasos de Nest Arch antes de asumir que un archivo o comando está presente.

El resultado generado es tuyo para modificar. Nest Arch crea el punto de partida, pero no sincroniza tu proyecto con versiones posteriores de la CLI.
