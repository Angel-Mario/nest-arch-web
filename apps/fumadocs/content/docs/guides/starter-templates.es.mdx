title: Plantillas iniciales
description: Elige una configuración predefinida y revísala antes de generar.
---

El menú de la TUI incluye **Starter templates**, que ofrece configuraciones predefinidas. Las plantillas disponibles pueden cambiar entre versiones.

Trata cada plantilla como un conjunto práctico de selecciones, no como garantía de compatibilidad con cualquier extra. Revisa el resumen, consulta la [guía de compatibilidad](../reference/compatibility) y sigue los pasos que aparezcan después de generar.

Para empezar, sigue el [inicio rápido](../getting-started/quick-start) de una API REST sin base de datos externa.
