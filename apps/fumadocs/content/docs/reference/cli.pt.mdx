---
title: Referência da CLI
description: Instale, execute e confira a versão do assistente Nest Arch.
---

O pacote `@nest-arch/tui` publica o executável `nest-arch`.

| Ação                           | Comando                                     |
| ------------------------------ | ------------------------------------------- |
| Executar 0.5.0 uma vez         | `npx @nest-arch/tui@0.5.0`                  |
| Executar a versão mais recente | `npx @nest-arch/tui@latest`                 |
| Instalar 0.5.0 globalmente     | `npm install --global @nest-arch/tui@0.5.0` |
| Iniciar a instalação global    | `nest-arch`                                 |
| Consultar a versão             | `nest-arch --version`                       |

Execute a CLI em um terminal interativo, na pasta onde deseja criar o projeto. Use uma pasta de saída nova. Este pacote da TUI não publica o comando `generate:module`.
