---
title: Inicio rápido
description: Genera una API REST NestJS y ejecuta el servidor de desarrollo.
---

Esta guía usa `@nest-arch/tui@latest` para crear una aplicación NestJS independiente con REST y Express, sin base de datos ni autenticación.

Ejecuta el asistente desde la carpeta donde quieras crear el proyecto:

```sh
npx @nest-arch/tui@latest
```

Selecciona `hello-nest` como nombre, elige npm (o un gestor instalado), **Express**, **Single project**, **NestJS API**, ninguna base de datos, **REST** y ninguna autenticación. Deja los extras y addons opcionales desactivados. Revisa el resumen y confirma la generación.

También puedes generar la misma API sin preguntas, usando npm y sin instalar dependencias ni inicializar Git:

```sh
npx @nest-arch/tui@latest hello-nest --package-manager npm --install-dependencies no --no-git
```

Elige uno de los dos métodos y usa una carpeta de salida nueva. Consulta la [guía headless](../guides/headless.mdx) para JSONC y otras opciones.

Si omitiste instalar las dependencias, ejecuta desde la carpeta nueva:

```sh
cd hello-nest
npm install
npm run dev
```

Si el asistente ya instaló las dependencias, basta con entrar a `hello-nest` y ejecutar `npm run dev`. Abre la URL local que imprime NestJS. Consulta la [primera ejecución](./first-run.mdx) si tu configuración requiere variables o servicios adicionales.
