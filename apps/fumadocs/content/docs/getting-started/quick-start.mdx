title: Quick start
description: Generate a small NestJS REST application and start its development server.
---

This walkthrough targets `@nest-arch/tui` **0.5.1** and creates a standalone NestJS REST API with Express, no database, and no authentication.

## Generate the project

Run the wizard from a parent directory where you want the new project created:

```sh
npx @nest-arch/tui@0.5.1
```

Choose these values when the corresponding steps appear:

| Wizard step          | Selection                                          |
| -------------------- | -------------------------------------------------- |
| Project name         | `hello-nest`                                       |
| Package manager      | A manager installed on your machine, such as `npm` |
| Formatter            | Biome, Oxlint + Oxfmt, or none                     |
| HTTP provider        | Express                                            |
| Project type         | Single project                                     |
| Architecture         | NestJS API                                         |
| Database             | None                                               |
| API layer            | REST                                               |
| Authentication       | None                                               |
| Git repository       | Choose whether to initialize Git                   |
| Install dependencies | Yes, or install them in the next section           |

Leave optional extras and addons unselected for this first project. Confirm the summary to generate the files.

## Start the server

You can also generate the same API without prompts, using npm and skipping dependency installation and Git:

```sh
npx @nest-arch/tui@0.5.1 hello-nest --package-manager npm --install-dependencies no --no-git
```

Choose one generation method and a fresh output directory. See the [headless guide](../guides/headless.mdx) for JSONC and more options.

Move into the project directory. If you skipped dependency installation in the wizard, install dependencies first:

```sh
cd hello-nest
npm install
```

Start the NestJS development server:

```sh
npm run dev
```

The generated project listens on the port configured by its environment file; open the local URL printed by NestJS. The `dev` script runs Nest in watch mode. See [first run](./first-run.mdx) for setup steps when your selected project needs a database or environment variables.
