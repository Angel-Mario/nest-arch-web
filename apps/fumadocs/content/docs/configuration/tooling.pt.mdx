---
title: Gerenciadores de pacotes e ferramentas
description: Escolha como instalar dependências e configurar a formatação.
---

Você pode escolher npm, pnpm, Yarn ou Bun. Selecione um gerenciador instalado. Se pular a instalação automática, execute o comando de instalação dentro do projeto.

A versão 0.5.1 oferece Biome, Oxlint + Oxfmt ou nenhuma ferramenta de formatação. A escolha altera os arquivos e scripts gerados. Confira `package.json` antes de executar `check` ou `fix`.

A inicialização do Git é opcional. Husky e Ultracite adicionam ferramentas e etapas de configuração; consulte [extras e addons](./extras-and-addons.mdx) e execute somente os comandos existentes no projeto.
