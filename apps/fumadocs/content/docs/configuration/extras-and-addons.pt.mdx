title: Extras e addons
description: Confira os recursos opcionais e seus requisitos.

Dependendo do perfil, podem aparecer extras como Docker, health checks, limite de solicitações, Swagger, exemplo Todo ou TypeScript 7. Os addons incluem Husky, Ultracite, agent skills, NestJS-Zod e Scalar UI.

O assistente filtra opções conforme projeto, provedor HTTP, API, banco de dados e ORM. A presença de um extra não certifica todas as combinações. Consulte o [guia de compatibilidade](../reference/compatibility.mdx) e siga os passos gerados.
