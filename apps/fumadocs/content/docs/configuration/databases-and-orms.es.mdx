---
title: Bases de datos y ORMs
description: Elige una base de datos y acceso a datos para un perfil validado.
---

La TUI lista PostgreSQL, MySQL, SQLite, SQL Server y MongoDB, además de Prisma, TypeORM y Drizzle. Las combinaciones permitidas varían; Drizzle se usa con bases de datos SQL y algunos perfiles MongoDB usan acceso nativo.

Selecciona como máximo una base de datos y un ORM. Un ORM requiere una base de datos. Después, puede que tengas que configurar `.env`, generar un cliente, aplicar un esquema o ejecutar migraciones. Sigue las instrucciones de tu proyecto.

No deduzcas compatibilidad combinando las opciones de forma independiente. Comprueba la [matriz de perfiles](../reference/compatibility.mdx). Para bases de datos externas, inicia el servicio primero; SQLite necesita que su archivo esté en una ruta escribible.
