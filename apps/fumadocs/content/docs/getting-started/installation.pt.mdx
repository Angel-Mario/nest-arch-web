---
title: Instalar o Nest Arch
description: Instale o Nest Arch e escolha o assistente interativo ou a geração headless.
---

Os comandos usam `@latest` para executar a versão mais recente publicada. A versão revisada para estes guias aparece abaixo do título. O Nest Arch está em fase alpha; as versões podem alterar o assistente e os arquivos gerados.

## Execute uma vez com npx

Use um terminal interativo e uma pasta nova para o projeto:

```sh
npx @nest-arch/tui@latest
```

Para recriar um projeto existente, use a versão registrada no seu `nest-arch.jsonc` em vez de `@latest`. Consulte a [reprodução de projetos](../guides/headless.mdx#reproduzir-um-projeto).

## Instalação global

```sh
npm install --global @nest-arch/tui@latest
nest-arch
```

Consulte a versão instalada com `nest-arch --version`. Não é necessário clonar o repositório para gerar uma aplicação. O assistente exige entrada interativa; para scripts e CI, use a [geração headless](../guides/headless.mdx) com um nome de projeto ou `--config`.
